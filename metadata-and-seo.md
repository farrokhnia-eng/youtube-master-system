# 13. DESCRIPTIONS, TRANSCRIPTS, CHAPTERS, AND METADATA

## 13.1 Four-Part Description Structure

### Part 1 — Opening Summary

The first two lines should:

- State the real subject;
- Explain the video's value;
- Match the title and opening;
- Use natural relevant keywords;
- Help viewers decide whether to watch.

### The 95-Character Claim

Preserve the suggestion to keep the opening summary under 95 characters as a testable formatting hypothesis. It is not an official YouTube requirement and does not guarantee that a link below it will appear without expanding the description. Display behavior depends on interface, device, and placement.

### Part 2 — CTA and Related Content

Use a relevant playlist, complementary video, useful file/resource, or meaningful call to action when appropriate. A playlist can make related videos easier to find, but it does not guarantee a higher session time or algorithmic reward.

### Part 3 — Social Links

Include real and useful links to Instagram, Telegram, a website, or other platforms. Never invent links or imply an affiliation that does not exist.

### Part 4 — Chapters, Sources, and Context

Add accurate chapters, sources, credits, an English summary when justified by audience strategy, and required disclosures.

## 13.2 Transcript-Based Description Workflow

When a transcript exists:

1. Read the full transcript.
2. Extract the main topics.
3. Identify natural, relevant phrases.
4. Flag factual claims requiring sources.
5. Map the narrative order.
6. Write a description that reflects the actual video.
7. Suggest chapters from real timestamps.
8. Remove anything not present in the final video.

Suggested workflow:

1. Upload privately or unlisted when review is needed.
2. Allow the required video quality processing to finish.
3. Obtain captions or a transcript.
4. Correct speech-to-text errors.
5. Generate description and chapter suggestions.
6. Compare them against the final video file.
7. Complete publishing settings.

Private or Unlisted visibility helps control access and review quality. A 24–48-hour private period is not an algorithmic requirement.

## 13.3 Chapters

- The first timestamp must be `00:00`.
- Include at least three timestamps.
- List timestamps in ascending order.
- Use accurate chapter titles.
- Match each timestamp to the real video.
- Follow the current YouTube minimum chapter-duration requirement. The documentation reviewed for the source version specified at least 10 seconds per chapter; recheck the live Help page before publishing.

Never invent timestamps when the final video or accurate timecodes are unavailable.

## 13.4 Three-Layer Tag System

**Layer 1:** The main topic phrase.  
**Layer 2:** Relevant long-tail phrases, often three to five words when natural.  
**Layer 3:** Four to six recurring channel identity tags, only if they accurately describe the video.

YouTube's official guidance says tags play a minimal role in discovery and are mainly useful for common misspellings and alternate forms. Do not make tags the primary SEO strategy. Do not claim recurring tags automatically connect videos or increase session time.

## 13.5 File Naming

Use descriptive file names such as `youtube-growth-strategy-final.mp4` for production organization. A direct ranking benefit from the local file name has not been established.
